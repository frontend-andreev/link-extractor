UTM タグを削除し、リダイレクトリンクを実際の URL に戻す方法

Chrome に追加 — 無料

結論：Link Extractor でフィルタと設定を開き、utm などのトラッキング パラメータを削除をオンにします。リダイレクトリンクは、すでに実際のアドレスで表示されます。リダイレクトではなく実際の URL が初期設定でオンだからです。どちらも、一覧、コピーした内容、CSV に反映されます。

2 つの別の問題

トラッキングタグは、クリック数を数えるためにアドレスに付け足されるパラメータです： https://shop.example/item?utm_source=newsletter&fbclid=…。タグがあってもなくてもページは同じですが、スプレッドシートではタグ付きのものが別のリンクに見えてしまい、一覧が長くなります。

リダイレクトリンクは、実際のアドレスを別のアドレスで包んだものです： https://www.google.com/url?q=https://example.com/ や https://l.facebook.com/l.php?u=…。そのままコピーすると、どの行も google.com や facebook.com で始まり、飛び先のサイトで並べ替えや絞り込みができません。

手順

  1. ページを開き、Link Extractor のアイコンをクリックします（Alt+Shift+L、Mac では Ctrl+Shift+L）。
  2. フィルタと設定を開きます。
  3. コピーとファイルの中で、utm などのトラッキング パラメータを削除をオンにします。リダイレクトではなく実際の URL はオンのままにします。
  4. 一覧を確認します。パネルにはURL から utm などのトラッキング パラメータを削除していますと表示され、リダイレクトリンクのうち何件が実際の URL で表示されているかも分かります。それぞれにリダイレクト経由の印が付き、印にカーソルを合わせると、ページにあったアドレスが表示されます。
  5. URL をコピーまたは CSV をクリックします。

設定は記憶され、次に開くページでも使われます。

削除されるタグ

すべての utm_… パラメータのほか、fbclid、gclid、 dclid、gbraid、wbraid、msclkid、 yclid、ysclid、igshid、mc_cid、 mc_eid、_hsenc、_hsmi、mkt_tok、 twclid、ttclid、li_fat_id、srsltid、 _ga、_gl です。

一覧は意図的に短くしています。ref、source、id のようなパラメータは、必要としているサイトがあり、削除するとリンクが壊れるため、残します。アドレスのそれ以外の部分は、パラメータの順序、エンコード、# より後ろの部分も含め、書かれているとおりに保たれます。トラッキングタグだけが違っていたリンクは 1 行にまとまります。

実際の URL に戻せるリダイレクトリンク

Google（/url?q=）、Bing（/ck/a）、DuckDuckGo、Facebook と Instagram の外部リンク、YouTube、LinkedIn、Reddit のリダイレクト、Outlook Safe Links、Slack、Steam、VK に対応しています。実際のアドレスはリンクそのものから読み取るため、何も開かず、リクエストも行いません。だから速く、プライバシーも守られます。

CSV では、url 列に実際のアドレスが入り、original_url に包まれたままのアドレスが残ります。ページにあるとおりのリンクを残したいときは、リダイレクトではなく実際の URLをオフにします。

できないこと

  • bit.ly や t.co のような短縮リンクは、飛び先を自社のサーバーに保持しています。それを知るにはリンクを開く必要があり、Link Extractor はネットワークリクエストを行わないため、そのままになります。それには URL 展開ツールを使ってください。
  • Google の検索結果には、実際のアドレスを隠しているものがあります。その場合、リンクには Google の意味のないコードしかありません。パネルはその行にGoogle が URL を非表示と表示し、推測せずに Google が渡したとおりにコピーします。検索結果のページでは、結果のみで、広告を除いた検索結果だけが順番に並びます。
  • javascript: や data: のアドレスを包んだリンクは、そのアドレスには変換されず、包まれたままになります。

よくある質問

タグを削除すると、ページが変わりますか？

いいえ。変わるのは一覧、コピー、ファイルだけです。ページとそのリンクはそのままです。

タグの削除が初期設定でオフなのはなぜですか？

初期設定では、ページにあるとおりのリンクを取得できるようにするためです。キャンペーンのリンクを確認するなど、タグが必要な方もいます。スイッチ 1 つでオンにできます。

どのリンクがリダイレクトだったか分かりますか？

はい。一覧ではリダイレクト経由の印が付き、CSV では元のアドレスが original_url 列に入ります。
