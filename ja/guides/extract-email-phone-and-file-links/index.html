Link Extractor · ガイド

ページからメール、電話、PDF のリンクを抽出する方法

Chrome に追加 — 無料

結論：ページを開いて Link Extractor のアイコンをクリックし、フィルタと設定を開いて、種類の中でメール、電話、ファイルのいずれかを選びます。一覧にはそのリンクだけが残り、URL をコピーまたは CSV で、それだけを取得できます。

こんな方に

チームの紹介ページ、ディレクトリ、仕入れ先の一覧から連絡先を集める方、そしてページからリンクされているすべての PDF、文書、アーカイブ（報告書、価格表、講座の資料、ダウンロードなど）が必要な方に向いています。

どのリンクがどの種類になるか

  • メール：mailto: のリンク。
  • 電話：tel: と sms: のリンク。
  • ファイル：アドレスの末尾がファイルの拡張子になっているリンク（PDF、Word、Excel、PowerPoint の文書、OpenDocument、RTF、TXT、CSV、EPUB、ZIP、RAR、7z などのアーカイブ、画像、音声と動画、インストーラーとディスクイメージ）と、ページ上でダウンロード用と指定されているすべてのリンク。
  • ページ：それ以外のすべての Web リンク。

種類で何も選ばない場合は、すべての種類が対象です。

手順

  1. ページを開き、Link Extractor のアイコンをクリックします（Alt+Shift+L、Mac では Ctrl+Shift+L）。
  2. フィルタと設定を開きます。
  3. 種類の中でメール、電話、ファイルを選びます。複数選ぶこともできます。
  4. 特定の種類のファイルだけにするには、検索ボックスにも入力します。.pdf なら PDF だけ、.docx なら Word の文書だけが残ります。
  5. URL をコピーをクリックするか、各リンクのリンクテキストと種類も入ったファイルが必要なら CSV をクリックします。

得られるもの

メールと電話のリンクは、たとえば mailto:sales@example.com や tel:+15551234567 のように、ページにあるとおりにコピーされ、一覧とファイルではリンクテキストが隣に付きます。重複はまとめられるので、ヘッダーとフッターの両方にあるアドレスも 1 行になります。ファイルのリンクは、開いたりダウンロードしたりできる完全な URL です。

上限について、率直に

  • 対象はリンクだけです。リンクではなく通常のテキストとして書かれたメールアドレスや電話番号は、一覧に入りません。Link Extractor はリンクを一覧にするもので、ページ内のテキストは検索しません。
  • ファイルはアドレスで判定します。/download?id=42 のような形で終わるダウンロードリンクには拡張子がないため、ページがダウンロード用と指定していない限り、ページとして扱われます。
  • ファイルそのものはダウンロードしません。取得できるのはファイルのアドレスで、ネットワークリクエストは行いません。
  • 内部と外部のフィルタでは、メールと電話のリンクは表示されません。サイトを持たないためです。

ほかのツールのほうが向いている場合

  • Web サイト全体の連絡先。Link Extractor はクロールをせず、開いている 1 つのページだけを読み取ります。
  • すべてのファイルを一度にダウンロードする。コピーした URL を、ダウンロードマネージャーに貼り付けてください。

よくある質問

メールアドレスは「mailto:」つきでコピーされますか？

はい。リンクはページにあるとおりに、?subject= の部分も含めてコピーされます。アドレスだけが必要なら、スプレッドシートの検索と置換で mailto: を削除してください。

フレームの中にあるページからリンクされた PDF も取得できますか？

はい。同じサイトのフレームは、ページと一緒に読み取られます。他のサイトのフレームにはお客様の許可が必要で、読み取れなかったときはパネルに表示されます。

無料ですか？

はい。アカウント不要で、有料機能はなく、リンクはブラウザの中にとどまります。

関連：リンクテキストと URL の組を Excel にコピーする。
