リンクテキストと URL の組を、ページの順序のまま Excel にコピーする方法

Chrome に追加 — 無料

結論：ページを開いて Link Extractor のアイコンをクリックし、URL をコピーの横のメニューを開いてExcel 用の表を選びます。Excel や Google スプレッドシートに貼り付けると、URL とリンクテキストがそれぞれ別の列に、リンク 1 件につき 1 行、ページの順序で入ります。

こんな方に

アンカーテキストを確認する SEO 担当者、情報源のリストを作る編集者、そしてページがどこにリンクしているかだけでなく、各リンクに何と書かれているかを知りたい方すべてに向いています。

テキストと URL をまとめて取得する 3 つの方法

  • Excel 用の表（URL をコピーの横のメニュー）：見出し行つきの表で、URL、テキスト、ドメイン、種類などが入ります。シートに貼り付けると列に分かれます。
  • テキスト — URL（同じメニュー）：「テキスト — アドレス」の組を 1 行ずつ。文書、メール、チャットに貼り付ける用途向けです。
  • CSV：同じ列のファイルで、保存しておいて後で開きたいときに。リンクを Excel 用の CSV に出力する方法をご覧ください。

同じメニューの URL は、アドレスだけを 1 行ずつコピーします。

手順

  1. ページを開き、Link Extractor のアイコンをクリックします（Alt+Shift+L、Mac では Ctrl+Shift+L）。
  2. 任意：検索ボックスかフィルタと設定で、一覧を絞り込みます。
  3. URL をコピーの横のメニューを開いて、Excel 用の表またはテキスト — URLを選びます。
  4. スプレッドシートや文書に貼り付けます。

テキストと順序の決まり方

  • テキストは、リンクに見えている文字で、余分なスペースと改行はまとめられます。画像のリンクでは画像の alt テキスト、それがなければリンクのラベルかタイトルです。テキストがまったくないリンクには、その旨の印が付きます。
  • 順序は、Web コンポーネントの中のリンクも含め、上から下へのページの順序です。
  • 繰り返しは、そのリンクが最初に現れた位置の 1 行にまとまり、ページに何回あるかが回数で表示されます。最初のものがテキストのない画像（商品写真やロゴ）の場合は、テキストのある後の方のものからテキストを取ります。
  • 完全なアドレス：/about のような相対リンクは、ブラウザが解決するのと同じ方法で、完全な URL になります。

ほかのツールのほうが向いている場合

  • 他のサイトから自分のサイトに向けられたリンク（被リンク）のアンカーテキスト。そのデータは Ahrefs や Semrush のような被リンクツールが持っています。Link Extractor が読み取るのは、開いているページです。
  • サイト全体のアンカーテキスト。Link Extractor はクロールをしません。それはサイト監査ツールの役目です。

よくある質問

繰り返しをまとめず、すべての出現を残せますか？

同じアドレスは、回数つきの常に 1 行です。重複では、# より後ろの部分だけ、または末尾のスラッシュだけが違うリンクもまとめるよう選べます。

Excel 用の表は Google スプレッドシートでも使えますか？

はい。セルに貼り付けると、同じように列が埋まります。

ページの一部だけから組を取得できますか？

はい。その部分を選択して右クリックし、選択範囲のリンクを取得を選んでから、上記のようにコピーします。

関連：メール、電話、ファイルのリンクを抽出する。
