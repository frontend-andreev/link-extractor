Link Extractor

開いているページのリンクをすべて、きれいな一覧に。完全な URL とリンクテキストを、ページの順序のまま、重複なしで。

Chrome ウェブストア · アカウント不要 · リンクはブラウザの外に出ません

できること

Link Extractor は、表示中のページのリンクを一覧にする無料の Chrome 拡張機能です。アイコンをクリックするとサイドパネルが開き、すべてのリンクがページの順序どおりに、完全な URL とリンクテキストの組で並びます。同じリンクは 1 行にまとめられ、回数が表示されます。一覧は検索できるほか、ドメイン、種類（ページ、ファイル、メール、電話）、内部リンクか外部リンクか、nofollow、sponsored、ugc で絞り込めます。Google、Bing、Facebook のリダイレクトリンクは、飛び先のアドレスで表示されます。あとは URL をコピーするか、Excel 用の CSV をダウンロードするだけ。長い一覧も途中で切れないので、数万件のリンクがあるページでも、すべてコピー・出力できます。ページはご自身のブラウザで、見えているとおりに読み取るため、JavaScript で追加されたリンクや、ログインが必要なページのリンクも含まれます。

主な機能

  • 開いているタブのすべてのリンクを、ページの順序で、完全な URL とリンクテキストの組として取得
  • 重複したリンクは 1 行にまとめ、回数を表示
  • 検索とフィルタ：ドメイン、種類、内部／外部、nofollow、sponsored、ugc
  • URL のコピー、または Excel や Google スプレッドシートに列ごとに貼り付けられる表のコピー
  • Excel で文字化けせずに開ける CSV ファイル
  • Google、Bing、Facebook のリダイレクトリンクではなく実際のアドレスを表示。utm タグは、必要に応じて削除
  • ページの選択した部分のリンクだけの取得、Google や Bing では検索結果だけの取得
  • 無料、アカウント不要。リンクはブラウザの外に出ません

ガイド

  • ページのすべてのリンクを、Excel で開ける CSV に出力する方法
  • UTM タグを削除し、リダイレクトリンクを実際の URL に戻す方法
  • 1 万件以上のリンクがある大きなページからすべてのリンクを抽出する方法
  • ページからメール、電話、PDF のリンクを抽出する方法
  • リンクテキストと URL の組を、ページの順序のまま Excel にコピーする方法

よくある質問

ブラウザからページのリンクをすべて CSV に出力するには？

ページを開き、Link Extractor のアイコンをクリックして（またはショートカットキー、初期設定では Alt+Shift+L、Mac では Ctrl+Shift+L）、CSV をクリックします。ファイルには、リンク 1 件につき 1 行、ページの順序で、完全な URL、リンクテキスト、ドメイン、種類などが入ります。

日本語、ロシア語、アラビア語などのリンクテキストは Excel で正しく開けますか？

はい。CSV はバイトオーダーマーク（BOM）付きの UTF-8 なので、Excel でどの言語の文字も正しく表示されます。区切り文字は Chrome の言語に合わせて決まります。Excel ですべてが 1 列にまとまってしまうときは、フィルタと設定の CSV の区切り文字でもう一方を選んでください。=、+、-、@ で始まる値は、Excel が数式として実行せず文字列のまま扱えるよう、先頭にアポストロフィが付きます。Excel のセルにそのアポストロフィが表示されることがあります。

1 万件以上のリンクも、途中で切れずに出力できますか？

はい。コピーも CSV ファイルも、一覧にあるすべてのリンクが対象で、途中で切れることはありません。当社のテストでは、1 万件のリンクがあるページが約 1 秒で一覧になり、その後もスクロールや絞り込みで固まることはありませんでした。パネルはページから最大 200,000 件、埋め込まれたフレームごとにも同じ数まで読み取り、それを超える場合はお知らせします。

リンクテキストと URL の組を、Excel に列ごとに貼り付けられる形でコピーするには？

URL をコピーの横のメニューを開いて Excel 用の表を選ぶと、Excel や Google スプレッドシートに貼り付けたとき、URL、テキスト、ドメイン、種類がそれぞれ別の列に入ります。テキスト — URL は「テキスト — アドレス」の組を 1 行ずつコピーし、URL はアドレスだけを 1 行ずつコピーします。

mailto や tel のリンクも抽出できますか？

はい。メール（mailto:）と電話（tel:、sms:）のリンクも、テキストとともに一覧に入り、ページにあるとおりにコピーされます。それだけを取り出すには、フィルタと設定で種類のメールまたは電話を選びます。

シングルページアプリや動的なサイトでも使えますか？

はい。スクリプトの実行後にタブにある状態のページを、Web コンポーネント（shadow DOM）も含めて読み取ります。スクロールや「もっと見る」で後からリンクが読み込まれるときは、スクロールしてからパネルの更新を押してください。アプリが同じサイトの別のページに移ったときは、一覧が自動で更新されます。

相対パスではなく、完全な絶対 URL で取得できますか？

はい。一覧、コピー、ファイルのアドレスはすべて、ブラウザが解決するのと同じ方法で解決した完全な URL です。<base> タグがあるページでも同様です。

取得した URL から UTM などのトラッキング パラメータを削除するには？

フィルタと設定でutm などのトラッキング パラメータを削除をオンにします。utm_source、fbclid、gclid などのトラッキング用タグが、一覧、コピー、ファイルから削除され、これらのタグだけが違っていたリンクは 1 つにまとまります。

重複したリンクはまとめられますか？

はい。同じアドレスは 1 回だけ表示され、ページに何回あるかが回数で表示されます。重複では、# より後ろの部分だけ、または末尾のスラッシュだけが違うリンクもまとめるよう選べます。

見えているリンクだけを残すには？

それが初期設定です。閉じたメニューや非表示のブロックにあるリンクは一覧に入りません。その件数はパネルに表示され、+N 件非表示で一覧に戻せます。

内部リンクと外部リンクの区別や、PDF や画像だけへの絞り込みはできますか？

はい。フィルタと設定には、内部／外部リンク、種類（ページ、ファイル、メール、電話）、ドメイン、nofollow、sponsored、ugc があります。ファイルには PDF、ZIP、画像などのファイルが含まれます。1 種類に絞るには、検索ボックスに .pdf のように入力します。

Google の検索結果のアドレスだけをきれいな一覧にするには？

Google や Bing の検索結果ページでは、パネルに結果のみが表示されます。広告や検索エンジン自身のリンクを除いた、検索結果だけが順番に並びます。

ページの一部だけのリンクを取得できますか？

はい。その部分を選択して右クリックし、選択範囲のリンクを取得を選ぶと、選択範囲の中にあるリンクだけが一覧になります。

登録は必要ですか？ リンクはどこかに送信されますか？

アカウントもログインも不要で、無料です。有料機能も広告もありません。一覧はブラウザの中で作られ、拡張機能はネットワークリクエストを一切行いません。リンクはクリップボードか、ダウンロードするファイルにだけ渡されます。当社のサイトでは、拡張機能のインストール数、低評価、削除の数を集計しています。具体的な内容はプライバシーポリシーをご覧ください。

できないことは？

開いているタブを対象にするので、サイト全体のクロールも、リンクをたどることも、リンクが有効かどうかの確認（ステータスコード）もしません。Chrome は拡張機能に Chrome ウェブストアのページや chrome:// ページの読み取りを許可しておらず、他のサイトから埋め込まれたフレームのリンクにはお客様の許可が必要です。パネルには、ページのどの部分を読み取れなかったかが表示されます。
