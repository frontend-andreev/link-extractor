How to export all links from a page to a CSV that opens in Excel

Add to Chrome — it's free

Short answer: install Link Extractor, open the page, click the extension's icon and click CSV. You get one row per link, in page order, with the full URL and the link text. The file is UTF-8 with a byte order mark, so Excel shows Cyrillic, Arabic, Chinese and accented text correctly.

Who this is for

SEO specialists checking the links of a page, marketers building outreach or competitor lists, researchers saving sources, and anyone who needs the links of one page in a spreadsheet instead of copying them by hand.

What a good export looks like

  • Full addresses. https://example.com/about, not /about.
  • The link text in its own column, next to the URL.
  • Page order, top to bottom, so the sheet matches what you see.
  • No duplicates: a link repeated in the menu and the footer is one row.
  • Readable text in Excel. Without a byte order mark, Excel often opens a UTF-8 file as Ð¿Ñ€Ð¸Ð²ÐµÑ‚ instead of the real letters.
  • The right separator. Excel in some countries expects a comma, in others a semicolon; with the wrong one, everything lands in column A.
  • Nothing cut off on long pages.

Step by step

  1. Open the page in Chrome. If it loads more links as you scroll or after “Show more”, scroll first.
  2. Click the Link Extractor icon in the toolbar, or press Alt+Shift+L (on a Mac, Ctrl+Shift+L). A side panel lists every link of the page.
  3. Optional: narrow the list. Type in the search box, or open Filters & settings for domain, type, internal or external links and nofollow, sponsored or ugc. The file contains the links now in the list.
  4. Click CSV. The file downloads at once.
  5. Open it in Excel by double-clicking it.

If Excel puts everything in one column

The separator does not match your Excel. After the download the panel asks Everything in one column in Excel? and offers to download the file again with the other separator. To change it for good, choose comma or semicolon under CSV separator in Filters & settings. By default (Auto) it follows the language of Chrome.

What is in the file

One row per link, with a header row: url, text, domain, scope (internal or external), type (page, file, email, phone), rel (nofollow, sponsored, ugc), count (how many times the link is on the page) and a few more. When a link went through a redirect such as google.com/url?q=…, the url column has the real address and original_url keeps the one from the page.

A value that starts with =, +, - or @ gets an apostrophe in front, so Excel keeps it as text and does not run it as a formula. Excel may show that apostrophe in the cell.

Without a file: paste straight into a sheet

Open the menu next to Copy URLs and choose Table for Excel, then paste into Excel or Google Sheets: URL, text, domain and type go into separate columns. For Google Sheets you can also import the CSV with File → Import.

When another tool is the better choice

  • Links from every page of a website. Link Extractor does not crawl: it reads the one tab you have open. For a whole site, use a site audit tool such as Screaming Frog SEO Spider.
  • Checking which links are broken. It does not check status codes; a link checker does.
  • Chrome Web Store and chrome:// pages. Chrome does not let any extension read them.

Questions

Are links added by JavaScript in the file?

Yes. The panel reads the page as it is in your tab, after its scripts have run, and pages behind your login too. An online extractor that loads the page from its own server sees neither.

Will a page with 10,000 links be exported in full?

Yes. The CSV includes every link in the list; nothing is cut off. The panel reads up to 200,000 links from a page and tells you if there are more.

Are links from hidden menus in the file?

Not by default: the list holds the links you can see, and the panel shows how many are hidden. Click +N hidden to add them to the list and the file.

Do I need an account? Where do my links go?

No account, and it is free. The list is built in your browser; the links go only to the file you download. See the privacy policy.
