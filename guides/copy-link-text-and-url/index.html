How to copy link text and URL pairs into Excel, in page order

Add to Chrome — it's free

Short answer: open the page, click the Link Extractor icon, open the menu next to Copy URLs and choose Table for Excel. Paste into Excel or Google Sheets: the URL and the link text land in their own columns, one row per link, in the order of the page.

Who this is for

SEO specialists checking anchor texts, editors building a list of sources, and anyone who needs to know not only where a page links but what each link says.

Three ways to get text and URL together

  • Table for Excel (in the menu next to Copy URLs): a table with a header row — URL, text, domain, type and more. Paste it into a sheet and it splits into columns.
  • Text — URL (same menu): one “text — address” pair per line, for a document, an email or a chat.
  • CSV: a file with the same columns, for when you want to keep it or open it later. See how to export links to a CSV for Excel.

URLs in the same menu copies only the addresses, one per line.

Step by step

  1. Open the page and click the Link Extractor icon (Alt+Shift+L, on a Mac Ctrl+Shift+L).
  2. Optional: narrow the list with the search box or Filters & settings.
  3. Open the menu next to Copy URLs and choose Table for Excel or Text — URL.
  4. Paste into your sheet or document.

How the text and the order are chosen

  • Text is what you see on the link, with extra spaces and line breaks collapsed. For an image link it is the image's alt text; if there is none, the link's label or title. A link with no text at all is marked as having none.
  • Order is the order of the page, top to bottom, including links inside web components.
  • Repeats are one row, placed where the link first appears, with a counter of how many times it is on the page. If the first copy is an image with no text (a product photo, a logo), the row takes the text of a later copy that has one.
  • Full addresses: relative links such as /about become full URLs, resolved the way the browser resolves them.

When another tool is the better choice

  • Anchor texts of links pointing to your site from other sites (backlinks). That data comes from backlink tools such as Ahrefs or Semrush; Link Extractor reads the page you have open.
  • Anchor texts across a whole site. Link Extractor does not crawl; a site audit tool does that.

Questions

Can I keep every occurrence instead of merging repeats?

The same address is always one row, with a counter. Under Duplicates you can choose to also merge links that differ only by the part after # or a slash at the end.

Does Table for Excel work in Google Sheets?

Yes. Paste it into a cell and it fills the columns the same way.

Can I get the pairs from only part of a page?

Yes. Select that part, right-click it and choose Extract links from the selection, then copy as above.
