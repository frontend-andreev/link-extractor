Comment exporter tous les liens d'une page en CSV lisible dans Excel

Ajouter à Chrome — gratuit

En bref : installez Link Extractor, ouvrez la page, cliquez sur l'icône de l'extension puis sur CSV. Vous obtenez une ligne par lien, dans l'ordre de la page, avec l'URL complète et le texte du lien. Le fichier est en UTF-8 avec une marque d'ordre des octets (BOM) : Excel affiche donc correctement le cyrillique, l'arabe, le chinois et les textes accentués.

À qui s'adresse ce guide

Aux spécialistes SEO qui vérifient les liens d'une page, aux marketeurs qui préparent des listes de prospection ou de concurrents, aux chercheurs qui conservent leurs sources, et à toute personne qui veut les liens d'une page dans un tableur plutôt que de les copier à la main.

À quoi ressemble un bon export

  • Des adresses complètes. https://example.com/about, et non /about.
  • Le texte du lien dans sa propre colonne, à côté de l'URL.
  • L'ordre de la page, de haut en bas, pour que le tableau corresponde à ce que vous voyez.
  • Aucun doublon : un lien répété dans le menu et dans le pied de page ne fait qu'une ligne.
  • Un texte lisible dans Excel. Sans marque d'ordre des octets, Excel ouvre souvent un fichier UTF-8 sous la forme Ð¿Ñ€Ð¸Ð²ÐµÑ‚ au lieu des vraies lettres.
  • Le bon séparateur. Selon le pays, Excel attend une virgule ou un point-virgule ; avec le mauvais, tout se retrouve dans la colonne A.
  • Rien de coupé sur les longues pages.

Pas à pas

  1. Ouvrez la page dans Chrome. Si elle charge d'autres liens pendant le défilement ou après « Afficher plus », faites d'abord défiler la page.
  2. Cliquez sur l'icône de Link Extractor dans la barre d'outils, ou appuyez sur Alt+Shift+L (sur Mac, Ctrl+Shift+L). Un panneau latéral liste tous les liens de la page.
  3. Facultatif : réduisez la liste. Tapez dans le champ de recherche, ou ouvrez Filtres et paramètres pour le domaine, le type, les liens internes ou externes et nofollow, sponsored ou ugc. Le fichier contient les liens présents dans la liste à ce moment-là.
  4. Cliquez sur CSV. Le fichier se télécharge aussitôt.
  5. Ouvrez-le dans Excel d'un double-clic.

Si Excel met tout dans une seule colonne

Le séparateur ne correspond pas à votre Excel. Après le téléchargement, le panneau demande Tout dans une seule colonne d'Excel ? et propose de télécharger de nouveau le fichier avec l'autre séparateur. Pour le changer définitivement, choisissez virgule ou point-virgule sous Séparateur CSV dans Filtres et paramètres. Par défaut (Auto), il suit la langue de Chrome.

Ce que contient le fichier

Une ligne par lien, avec une ligne d'en-tête : url, text, domain, scope (interne ou externe), type (page, fichier, e-mail, téléphone), rel (nofollow, sponsored, ugc), count (combien de fois le lien est sur la page) et quelques autres. Quand un lien passait par une redirection comme google.com/url?q=…, la colonne url contient la vraie adresse et original_url garde celle de la page.

Une valeur qui commence par =, +, - ou @ reçoit une apostrophe devant, pour qu'Excel la garde comme du texte et ne l'exécute pas comme une formule. Excel peut afficher cette apostrophe dans la cellule.

Sans fichier : coller directement dans un tableur

Ouvrez le menu à côté de Copier les URL et choisissez Tableau pour Excel, puis collez dans Excel ou Google Sheets : l'URL, le texte, le domaine et le type vont dans des colonnes séparées. Dans Google Sheets, vous pouvez aussi importer le CSV avec Fichier → Importer.

Quand un autre outil est plus adapté

  • Les liens de toutes les pages d'un site. Link Extractor n'explore pas : il lit l'unique onglet que vous avez ouvert. Pour un site entier, utilisez un outil d'audit de site comme Screaming Frog SEO Spider.
  • Repérer les liens cassés. Il ne vérifie pas les codes d'état ; un vérificateur de liens, si.
  • Les pages du Chrome Web Store et chrome://. Chrome ne permet à aucune extension de les lire.

Questions

Les liens ajoutés par JavaScript sont-ils dans le fichier ?

Oui. Le panneau lit la page telle qu'elle est dans votre onglet, une fois ses scripts exécutés, y compris les pages derrière votre connexion. Un extracteur en ligne qui charge la page depuis son propre serveur ne voit ni les uns ni les autres.

Une page de 10 000 liens est-elle exportée en entier ?

Oui. Le CSV contient tous les liens de la liste ; rien n'est coupé. Le panneau lit jusqu'à 200 000 liens sur une page et vous prévient s'il y en a davantage.

Les liens des menus masqués sont-ils dans le fichier ?

Pas par défaut : la liste contient les liens que vous voyez, et le panneau indique combien sont masqués. Cliquez sur +N masqués pour les ajouter à la liste et au fichier.

Faut-il un compte ? Où vont mes liens ?

Pas de compte, et c'est gratuit. La liste est construite dans votre navigateur ; les liens vont uniquement dans le fichier que vous téléchargez. Voir la politique de confidentialité.
