Comment copier le texte et l'URL des liens dans Excel, dans l'ordre de la page

Ajouter à Chrome — gratuit

En bref : ouvrez la page, cliquez sur l'icône de Link Extractor, ouvrez le menu à côté de Copier les URL et choisissez Tableau pour Excel. Collez dans Excel ou Google Sheets : l'URL et le texte du lien se retrouvent dans leurs propres colonnes, une ligne par lien, dans l'ordre de la page.

À qui s'adresse ce guide

Aux spécialistes SEO qui vérifient les textes d'ancre, aux rédacteurs qui constituent une liste de sources, et à toute personne qui veut savoir non seulement vers où une page renvoie, mais aussi ce que dit chaque lien.

Trois façons d'obtenir le texte et l'URL ensemble

  • Tableau pour Excel (dans le menu à côté de Copier les URL) : un tableau avec une ligne d'en-tête — URL, texte, domaine, type et plus. Collez-le dans une feuille et il se répartit en colonnes.
  • Texte — URL (même menu) : une paire « texte — adresse » par ligne, pour un document, un e-mail ou une messagerie.
  • CSV : un fichier avec les mêmes colonnes, pour le conserver ou l'ouvrir plus tard. Voir comment exporter les liens en CSV pour Excel.

URL, dans le même menu, ne copie que les adresses, une par ligne.

Pas à pas

  1. Ouvrez la page et cliquez sur l'icône de Link Extractor (Alt+Shift+L, sur Mac Ctrl+Shift+L).
  2. Facultatif : réduisez la liste avec le champ de recherche ou Filtres et paramètres.
  3. Ouvrez le menu à côté de Copier les URL et choisissez Tableau pour Excel ou Texte — URL.
  4. Collez dans votre feuille ou votre document.

Comment le texte et l'ordre sont déterminés

  • Le texte est ce que vous voyez sur le lien, les espaces superflus et les sauts de ligne étant réduits. Pour un lien image, c'est le texte alternatif de l'image ; s'il n'y en a pas, l'étiquette ou le titre du lien. Un lien sans aucun texte est signalé comme n'en ayant pas.
  • L'ordre est celui de la page, de haut en bas, y compris les liens situés dans les composants Web.
  • Les répétitions forment une seule ligne, placée là où le lien apparaît la première fois, avec un compteur du nombre de fois où il est sur la page. Si la première occurrence est une image sans texte (photo de produit, logo), la ligne prend le texte d'une occurrence suivante qui en a un.
  • Des adresses complètes : les liens relatifs comme /about deviennent des URL complètes, résolues comme le fait le navigateur.

Quand un autre outil est plus adapté

  • Les textes d'ancre des liens d'autres sites vers le vôtre (backlinks). Ces données viennent d'outils de backlinks comme Ahrefs ou Semrush ; Link Extractor lit la page que vous avez ouverte.
  • Les textes d'ancre de tout un site. Link Extractor n'explore pas ; un outil d'audit de site le fait.

Questions

Puis-je garder chaque occurrence au lieu de fusionner les répétitions ?

Une même adresse ne fait toujours qu'une ligne, avec un compteur. Sous Doublons, vous pouvez choisir de fusionner aussi les liens qui ne diffèrent que par la partie après # ou par une barre oblique à la fin.

Le Tableau pour Excel fonctionne-t-il dans Google Sheets ?

Oui. Collez-le dans une cellule et il remplit les colonnes de la même façon.

Puis-je obtenir les paires d'une partie seulement d'une page ?

Oui. Sélectionnez cette partie, faites un clic droit puis choisissez Récupérer les liens de la sélection, et copiez comme ci-dessus.
