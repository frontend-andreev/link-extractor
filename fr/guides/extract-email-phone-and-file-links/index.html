Link Extractor · Guides

Comment extraire les liens e-mail, téléphone et PDF d'une page

Ajouter à Chrome — gratuit

En bref : ouvrez la page, cliquez sur l'icône de Link Extractor, ouvrez Filtres et paramètres et, sous Type, choisissez E-mail, Téléphones ou Fichiers. La liste ne garde que ces liens, et Copier les URL ou CSV ne vous donne qu'eux.

À qui s'adresse ce guide

À toute personne qui rassemble des contacts depuis une page d'équipe, un annuaire ou une liste de fournisseurs, et à toute personne qui veut tous les PDF, documents ou archives liés depuis une page : rapports, tarifs, supports de cours, téléchargements.

Quels liens comptent pour quoi

  • E-mail : les liens mailto:.
  • Téléphones : les liens tel: et sms:.
  • Fichiers : les liens dont l'adresse se termine par une extension de fichier — PDF ; documents Word, Excel et PowerPoint ; OpenDocument, RTF, TXT, CSV et EPUB ; ZIP, RAR, 7z et autres archives ; images ; audio et vidéo ; programmes d'installation et images disque — et tout lien marqué comme téléchargement sur la page.
  • Pages : tous les autres liens Web.

Si rien n'est sélectionné sous Type, tous les types sont affichés.

Pas à pas

  1. Ouvrez la page et cliquez sur l'icône de Link Extractor (Alt+Shift+L, sur Mac Ctrl+Shift+L).
  2. Ouvrez Filtres et paramètres.
  3. Sous Type, choisissez E-mail, Téléphones ou Fichiers ; vous pouvez en choisir plusieurs.
  4. Pour un seul genre de fichier, tapez-le aussi dans le champ de recherche : .pdf ne garde que les PDF, .docx que les documents Word.
  5. Cliquez sur Copier les URL, ou sur CSV pour un fichier avec le texte et le type de chaque lien.

Ce que vous obtenez

Les liens e-mail et téléphone sont copiés exactement comme sur la page, par exemple mailto:sales@example.com ou tel:+15551234567, avec le texte du lien à côté dans la liste et dans le fichier. Les doublons sont fusionnés : une adresse présente dans l'en-tête et dans le pied de page ne fait qu'une ligne. Les liens de fichiers sont des URL complètes que vous pouvez ouvrir ou télécharger.

Les limites, en toute franchise

  • Uniquement des liens. Une adresse e-mail ou un numéro de téléphone écrit en texte simple, et non sous forme de lien, n'est pas dans la liste. Link Extractor liste des liens ; il ne cherche pas dans le texte de la page.
  • Les fichiers sont reconnus à leur adresse. Un lien de téléchargement qui se termine par quelque chose comme /download?id=42 n'a pas d'extension ; il est compté comme une page, sauf si la page le marque comme téléchargement.
  • Elle ne télécharge pas les fichiers. Vous obtenez leurs adresses ; elle ne fait aucune requête réseau.
  • Les filtres Internes et Externes masquent les liens e-mail et téléphone, car ils n'ont pas de site.

Quand un autre outil est plus adapté

  • Les contacts de tout un site Web. Link Extractor n'explore pas ; il lit la seule page que vous avez ouverte.
  • Télécharger tous les fichiers d'un coup. Collez les URL copiées dans un gestionnaire de téléchargement.

Questions

L'adresse e-mail est-elle copiée avec « mailto: » ?

Oui, le lien est copié tel que la page le contient, y compris une éventuelle partie ?subject=. Pour obtenir les adresses seules, supprimez mailto: avec la fonction Rechercher/Remplacer de votre tableur.

Peut-on récupérer les PDF liés depuis un cadre intégré à la page ?

Oui, les cadres du même site sont lus avec la page. Les cadres d'autres sites demandent votre autorisation, et le panneau indique quand il n'a pas pu en lire un.

Est-ce gratuit ?

Oui. Sans compte, sans fonctions payantes, et les liens restent dans votre navigateur.
