Як скопіювати пари «текст посилання — URL» в Excel у порядку сторінки

Додати в Chrome — це безкоштовно

Коротко: відкрийте сторінку, натисніть значок Link Extractor, відкрийте меню поруч із Copy URLs і виберіть Table for Excel. Вставте в Excel чи Google Таблиці: URL і текст посилання потраплять в окремі стовпці, один рядок на посилання, у порядку сторінки.

Для кого це

Для SEO-спеціалістів, які перевіряють анкорні тексти, редакторів, що складають список джерел, і всіх, кому важливо знати не лише, куди веде сторінка, а й що написано на кожному посиланні.

Три способи отримати текст і URL разом

  • Table for Excel (у меню поруч із Copy URLs): таблиця з рядком заголовків — URL, текст, домен, тип та інше. Вставте її в таблицю — і вона розкладеться по стовпцях.
  • Text — URL (те саме меню): одна пара «текст — адреса» в рядку, для документа, листа чи чату.
  • CSV: файл із тими самими стовпцями, щоб зберегти його або відкрити пізніше. Див. як експортувати посилання в CSV для Excel.

URLs у тому самому меню копіює лише адреси, по одній в рядку.

Покроково

  1. Відкрийте сторінку й натисніть значок Link Extractor (Alt+Shift+L, на Mac Ctrl+Shift+L).
  2. За бажанням звузьте список полем пошуку або Filters & settings.
  3. Відкрийте меню поруч із Copy URLs і виберіть Table for Excel або Text — URL.
  4. Вставте в таблицю чи документ.

Як вибираються текст і порядок

  • Текст — те, що ви бачите на посиланні, із зведеними зайвими пробілами й розривами рядків. Для посилання-зображення це альтернативний текст зображення, а якщо його немає — підпис або заголовок посилання. Посилання без жодного тексту позначається як таке, що його не має.
  • Порядок — порядок сторінки згори вниз, зокрема посилання всередині веб-компонентів.
  • Повтори — один рядок на тому місці, де посилання з’явилося вперше, з лічильником того, скільки разів воно є на сторінці. Якщо перша копія — зображення без тексту (фото товару, логотип), рядок бере текст пізнішої копії, де він є.
  • Повні адреси: відносні посилання на кшталт /about стають повними URL, розв’язаними так, як це робить браузер.

Коли краще інший інструмент

  • Анкорні тексти посилань на ваш сайт з інших сайтів (бекліни). Ці дані дають інструменти для аналізу беклінків, як-от Ahrefs чи Semrush; Link Extractor читає відкриту вами сторінку.
  • Анкорні тексти з усього сайту. Link Extractor не обходить сайт; це робить інструмент аудиту сайту.

Питання

Чи можна зберегти кожне входження замість зведення повторів?

Та сама адреса завжди один рядок, із лічильником. У розділі Duplicates можна вибрати також зведення посилань, що відрізняються лише частиною після # або слешем у кінці.

Чи працює Table for Excel у Google Таблицях?

Так. Вставте в клітинку — і вона так само заповнить стовпці.

Чи можна отримати пари лише з частини сторінки?

Так. Виділіть цю частину, клацніть правою кнопкою миші й виберіть Extract links from the selection, а потім копіюйте, як описано вище.

Також: витягніть посилання на email, телефони та файли.
