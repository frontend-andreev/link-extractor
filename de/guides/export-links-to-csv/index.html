Link Extractor · Anleitungen

So exportieren Sie alle Links einer Seite in eine CSV, die sich in Excel öffnet

Zu Chrome hinzufügen — kostenlos

Kurz gesagt: Installieren Sie Link Extractor, öffnen Sie die Seite, klicken Sie auf das Symbol der Erweiterung und dann auf CSV. Sie bekommen eine Zeile pro Link, in Seitenreihenfolge, mit der vollständigen URL und dem Linktext. Die Datei ist UTF-8 mit Byte-Order-Mark, daher zeigt Excel kyrillischen, arabischen und chinesischen Text sowie Umlaute und Akzente richtig an.

Für wen das gedacht ist

Für SEO-Fachleute, die die Links einer Seite prüfen, Marketer, die Outreach- oder Wettbewerberlisten aufbauen, Forschende, die Quellen sichern, und alle, die die Links einer Seite in einer Tabelle brauchen, statt sie von Hand zu kopieren.

Wie ein guter Export aussieht

  • Vollständige Adressen. https://example.com/about, nicht /about.
  • Der Linktext in einer eigenen Spalte neben der URL.
  • Seitenreihenfolge, von oben nach unten, damit die Tabelle zu dem passt, was Sie sehen.
  • Keine Duplikate: Ein Link, der im Menü und in der Fußzeile steht, ist eine Zeile.
  • Lesbarer Text in Excel. Ohne Byte-Order-Mark öffnet Excel eine UTF-8-Datei oft als Ð¿Ñ€Ð¸Ð²ÐµÑ‚ statt mit den echten Buchstaben.
  • Das richtige Trennzeichen. Excel erwartet in manchen Ländern ein Komma, in anderen ein Semikolon; mit dem falschen landet alles in Spalte A.
  • Nichts abgeschnitten bei langen Seiten.

Schritt für Schritt

  1. Öffnen Sie die Seite in Chrome. Lädt sie beim Scrollen oder nach „Mehr anzeigen“ weitere Links nach, scrollen Sie zuerst.
  2. Klicken Sie in der Symbolleiste auf das Symbol von Link Extractor oder drücken Sie Alt+Shift+L (auf dem Mac Ctrl+Shift+L). Ein Seitenpanel listet jeden Link der Seite auf.
  3. Optional: Grenzen Sie die Liste ein. Tippen Sie ins Suchfeld oder öffnen Sie Filter & Einstellungen für Domain, Typ, interne oder externe Links sowie nofollow, sponsored oder ugc. Die Datei enthält die Links, die jetzt in der Liste stehen.
  4. Klicken Sie auf CSV. Die Datei wird sofort heruntergeladen.
  5. Öffnen Sie sie in Excel per Doppelklick.

Wenn Excel alles in eine Spalte schreibt

Das Trennzeichen passt nicht zu Ihrem Excel. Nach dem Download fragt das Panel In Excel alles in einer Spalte? und bietet an, die Datei mit dem anderen Trennzeichen erneut herunterzuladen. Um es dauerhaft zu ändern, wählen Sie unter CSV-Trennzeichen in Filter & Einstellungen Komma oder Semikolon. Standardmäßig (Auto) richtet es sich nach der Sprache von Chrome.

Was in der Datei steht

Eine Zeile pro Link, mit einer Kopfzeile: url, text, domain, scope (intern oder extern), type (Seite, Datei, E-Mail, Telefon), rel (nofollow, sponsored, ugc), count (wie oft der Link auf der Seite steht) und einige weitere. Ist ein Link über eine Weiterleitung wie google.com/url?q=… gelaufen, steht in der Spalte url die echte Adresse, und original_url behält die von der Seite.

Ein Wert, der mit =, +, - oder @ beginnt, bekommt ein Apostroph davor, damit Excel ihn als Text behält und nicht als Formel ausführt. Excel zeigt dieses Apostroph unter Umständen in der Zelle an.

Ohne Datei: direkt in eine Tabelle einfügen

Öffnen Sie das Menü neben URLs kopieren und wählen Sie Tabelle für Excel, dann fügen Sie in Excel oder Google Sheets ein: URL, Text, Domain und Typ landen in getrennten Spalten. Für Google Sheets können Sie die CSV auch mit Datei → Importieren laden.

Wann ein anderes Werkzeug besser ist

  • Links von jeder Seite einer Website. Link Extractor durchsucht keine Websites: Es liest den einen Tab, den Sie geöffnet haben. Für eine ganze Website nehmen Sie ein Werkzeug für Website-Audits wie Screaming Frog SEO Spider.
  • Prüfen, welche Links defekt sind. Es prüft keine Statuscodes; das macht ein Link-Checker.
  • Seiten des Chrome Web Store und chrome://-Seiten. Chrome erlaubt keiner Erweiterung, sie zu lesen.

Fragen

Sind per JavaScript hinzugefügte Links in der Datei?

Ja. Das Panel liest die Seite so, wie sie in Ihrem Tab steht, nachdem ihre Skripte gelaufen sind, und auch Seiten hinter Ihrem Login. Ein Online-Extraktor, der die Seite von seinem eigenen Server lädt, sieht beides nicht.

Wird eine Seite mit 10.000 Links vollständig exportiert?

Ja. Die CSV enthält jeden Link der Liste; nichts wird abgeschnitten. Das Panel liest bis zu 200.000 Links von einer Seite und sagt Ihnen, wenn es mehr gibt.

Sind Links aus versteckten Menüs in der Datei?

Standardmäßig nicht: Die Liste enthält die Links, die Sie sehen können, und das Panel zeigt, wie viele ausgeblendet sind. Klicken Sie auf +N ausgeblendet, um sie zur Liste und zur Datei hinzuzufügen.

Brauche ich ein Konto? Wohin gehen meine Links?

Kein Konto, und es ist kostenlos. Die Liste entsteht in Ihrem Browser; die Links gehen nur in die Datei, die Sie herunterladen. Siehe die Datenschutzerklärung.

Siehe auch: UTM-Tags entfernen und Weiterleitungslinks auflösen vor dem Export.
