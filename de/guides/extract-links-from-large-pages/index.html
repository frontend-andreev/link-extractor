Link Extractor · Anleitungen

So extrahieren Sie alle Links einer großen Seite mit über 10.000 Links

Zu Chrome hinzufügen — kostenlos

Kurz gesagt: Öffnen Sie die Seite, lassen Sie sie ihren ganzen Inhalt laden, klicken Sie auf das Symbol von Link Extractor und nutzen Sie URLs kopieren oder CSV. Das Kopieren und die Datei enthalten jeden Link der Liste, nichts wird abgeschnitten. In unseren Tests wird eine Seite mit 10.000 Links in etwa einer Sekunde aufgelistet, und die Liste lässt sich weiter ohne Ruckeln scrollen und filtern.

Für wen das gedacht ist

Für alle, die mit langen Seiten arbeiten: Sitemaps und Archivseiten, Verzeichnisse und Kataloge, Linklisten, Dokumentationsverzeichnisse, lange Forenthreads, Feeds, die beim Scrollen weiterladen. Viele Link-Extraktoren werden dort langsam, frieren den Tab ein oder hören stillschweigend nach ein paar hundert oder ein paar tausend Links auf.

Worauf es bei einer großen Seite ankommt

  • Ein vollständiges Ergebnis. Wenn das Werkzeug vorzeitig aufhört, sollte es das sagen, statt Ihnen einen Teil der Seite als das Ganze zu geben.
  • Die Seite zuerst laden. Links, die erst nach dem Scrollen oder nach „Mehr anzeigen“ erscheinen, sind beim Start noch nicht auf der Seite.
  • Eine flüssige Liste, damit Sie Zehntausende Zeilen durchsuchen und filtern können.
  • Zusammengefasste Duplikate: Auf großen Seiten wiederholen sich dieselben Links oft.

Schritt für Schritt

  1. Öffnen Sie die Seite. Lädt sie beim Scrollen mehr nach, scrollen Sie bis zum Ende oder klicken Sie auf „Mehr anzeigen“, bis alles, was Sie brauchen, auf der Seite ist.
  2. Klicken Sie auf das Symbol von Link Extractor oder drücken Sie Alt+Shift+L (auf dem Mac Ctrl+Shift+L). Das Seitenpanel listet die Links in Seitenreihenfolge auf; Wiederholungen sind eine Zeile mit Zähler.
  3. Wenn Sie nach dem Öffnen des Panels weitergescrollt haben, klicken Sie im Panel auf Aktualisieren, um zu ergänzen, was seitdem geladen wurde.
  4. Optional: Tippen Sie ins Suchfeld oder öffnen Sie Filter & Einstellungen, um nur die Links zu behalten, die Sie brauchen, zum Beispiel eine Domain oder nur externe Links.
  5. Klicken Sie auf URLs kopieren, um sie zu kopieren, eine pro Zeile, oder auf CSV, um eine Datei herunterzuladen.

Grenzen, offen gesagt

  • Das Panel liest bis zu 200.000 Links von einer Seite und ebenso viele aus jedem eingebetteten Frame. Hat eine Seite mehr, sagt das Panel Nur die ersten 200.000 Links sind in der Liste.
  • Links in geschlossenen Menüs und versteckten Blöcken bleiben standardmäßig draußen, und das Panel zeigt, wie viele es sind. +N ausgeblendet holt sie dazu.
  • Excel fasst höchstens 32.767 Zeichen in einer Zelle. Ist eine URL oder ein Linktext länger, wird diese Zelle in der CSV gekürzt, und das Panel sagt Ihnen, wie viele Zellen gekürzt wurden.
  • Links in Frames, die von anderen Websites eingebettet sind, brauchen Ihre Erlaubnis; das Panel sagt, welchen Teil der Seite es nicht lesen konnte.

Wann ein anderes Werkzeug besser ist

  • Links von vielen Seiten einer Website. Link Extractor durchsucht keine Websites: Es liest den einen Tab, den Sie geöffnet haben. Für eine ganze Website nehmen Sie ein Werkzeug für Website-Audits wie Screaming Frog SEO Spider.

Fragen

Friert der Tab ein, während 10.000+ Links gelesen werden?

Nein. Das Panel zeichnet nur die Zeilen, die Sie sehen können, daher bleiben Scrollen und Filtern auch bei Zehntausenden Links schnell.

Wird das Kopieren bei einer bestimmten Zeilenzahl abgeschnitten?

Nein. URLs kopieren und CSV nehmen jeden Link der Liste, nach Ihrer Suche und Ihren Filtern.

Erfasst sie Links, die per Endlos-Scrollen nachgeladen werden?

Ja, sobald sie auf der Seite sind. Scrollen Sie, bis sie geladen sind, und klicken Sie dann auf Aktualisieren. Die Seite scrollt sie nicht für Sie.
