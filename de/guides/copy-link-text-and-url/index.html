Link Extractor · Anleitungen

So kopieren Sie Linktext und URL als Paare in Excel, in Seitenreihenfolge

Zu Chrome hinzufügen — kostenlos

Kurz gesagt: Öffnen Sie die Seite, klicken Sie auf das Symbol von Link Extractor, öffnen Sie das Menü neben URLs kopieren und wählen Sie Tabelle für Excel. Fügen Sie den Inhalt in Excel oder Google Sheets ein: URL und Linktext landen in eigenen Spalten, eine Zeile pro Link, in der Reihenfolge der Seite.

Für wen das gedacht ist

SEO-Fachleute, die Ankertexte prüfen, Redakteure, die eine Quellenliste aufbauen, und alle, die nicht nur wissen müssen, wohin eine Seite verlinkt, sondern auch, was jeder Link sagt.

Drei Wege, Text und URL zusammen zu bekommen

  • Tabelle für Excel (im Menü neben URLs kopieren): eine Tabelle mit Kopfzeile — URL, Text, Domain, Typ und mehr. Fügen Sie sie in ein Tabellenblatt ein, und sie verteilt sich auf Spalten.
  • Linktext — URL (im selben Menü): ein Paar „Text — Adresse“ pro Zeile, für ein Dokument, eine E-Mail oder einen Chat.
  • CSV: eine Datei mit denselben Spalten, wenn Sie sie aufbewahren oder später öffnen möchten. Siehe So exportieren Sie Links in eine CSV für Excel.

URLs im selben Menü kopiert nur die Adressen, eine pro Zeile.

Schritt für Schritt

  1. Öffnen Sie die Seite und klicken Sie auf das Symbol von Link Extractor (Alt+Shift+L, auf dem Mac Ctrl+Shift+L).
  2. Optional: Grenzen Sie die Liste mit dem Suchfeld oder Filter & Einstellungen ein.
  3. Öffnen Sie das Menü neben URLs kopieren und wählen Sie Tabelle für Excel oder Linktext — URL.
  4. Fügen Sie den Inhalt in Ihr Tabellenblatt oder Dokument ein.

Wie Text und Reihenfolge bestimmt werden

  • Text ist das, was Sie auf dem Link sehen, mit zusammengefassten Leerzeichen und Zeilenumbrüchen. Bei einem Bildlink ist es der Alt-Text des Bildes; gibt es keinen, die Beschriftung oder der Titel des Links. Ein Link ganz ohne Text wird als textlos markiert.
  • Reihenfolge ist die Reihenfolge der Seite, von oben nach unten, einschließlich Links in Webkomponenten.
  • Wiederholungen sind eine Zeile, an der Stelle, wo der Link zum ersten Mal vorkommt, mit einem Zähler, wie oft er auf der Seite steht. Ist die erste Kopie ein Bild ohne Text (ein Produktfoto, ein Logo), übernimmt die Zeile den Text einer späteren Kopie, die einen hat.
  • Vollständige Adressen: relative Links wie /about werden zu vollständigen URLs, aufgelöst so, wie der Browser sie auflöst.

Wann ein anderes Werkzeug besser ist

  • Ankertexte von Links, die von anderen Websites auf Ihre Website zeigen (Backlinks). Diese Daten liefern Backlink-Tools wie Ahrefs oder Semrush; Link Extractor liest die Seite, die Sie geöffnet haben.
  • Ankertexte einer ganzen Website. Link Extractor durchsucht keine Websites; das übernimmt ein Werkzeug für Website-Audits.

Fragen

Kann ich jedes Vorkommen behalten, statt Wiederholungen zusammenzufassen?

Dieselbe Adresse ist immer eine Zeile, mit einem Zähler. Unter Duplikate können Sie wählen, auch Links zusammenzufassen, die sich nur im Teil nach # oder durch einen Schrägstrich am Ende unterscheiden.

Funktioniert Tabelle für Excel in Google Sheets?

Ja. Fügen Sie sie in eine Zelle ein, und sie füllt die Spalten auf dieselbe Weise.

Kann ich die Paare nur aus einem Teil der Seite bekommen?

Ja. Markieren Sie diesen Teil, klicken Sie mit der rechten Maustaste darauf und wählen Sie Links aus der Auswahl sammeln, dann kopieren Sie wie oben.
