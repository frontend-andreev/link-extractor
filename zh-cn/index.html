功能简介

Link Extractor 是一款免费的 Chrome 扩展，能列出你正在浏览的网页上的链接。点击它的图标，侧边栏会按页面顺序显示每一个链接：完整网址，旁边是链接文字；重复的链接合并为一行，并带有计数。你可以在列表中搜索，也可以按域名、类型（网页、文件、邮箱、电话）、站内或站外链接，以及 nofollow、sponsored、ugc 来过滤。来自 Google、Bing 或 Facebook 的重定向链接，会显示它们真正指向的地址。之后可以复制网址，或下载供 Excel 使用的 CSV；长列表不会被截断，所以有几万个链接的页面也能完整复制和导出。它在你自己的浏览器里按你看到的样子读取页面，因此由 JavaScript 添加的链接和需要登录才能看到的页面也包括在内。

  • 搜索和过滤：域名、类型、站内或站外、nofollow、sponsored、ugc

常见问题

如何在浏览器中把网页上的所有链接导出为 CSV？

打开网页，点击 Link Extractor 图标（或按快捷键，默认是 Alt+Shift+L，Mac 上是 Ctrl+Shift+L），然后点击 CSV。文件中每个链接一行，按页面顺序排列，包含完整网址、链接文字、域名、类型等信息。

中文、西里尔文或阿拉伯文的链接文字在 Excel 中能正常显示吗？

可以。CSV 采用带字节顺序标记（BOM）的 UTF-8 编码，所以 Excel 能正确显示各种文字；分隔符会跟随 Chrome 的语言，如果 Excel 把所有内容都放进了一列，请在“过滤和设置”的 CSV 分隔符 中换成另一种。以 =、+、- 或 @ 开头的值，前面会加一个撇号，这样 Excel 会把它当作文本，而不是当作公式运行；Excel 可能会在单元格里显示这个撇号。

能完整导出 10,000 多个链接而不被截断吗？

能。复制和 CSV 文件包含列表中的每一个链接，不会被截断。在我们的测试中，有 10,000 个链接的页面大约一秒就能列出，列表依然可以流畅滚动和过滤，不会卡住。侧边栏最多从页面读取 200,000 个链接，每个嵌入框架也是如此，超出时会提示你。

如何复制链接文字和网址的配对，并按列粘贴到 Excel？

打开 复制网址 旁边的菜单，选择 Excel 表格：粘贴到 Excel 或 Google 表格时，网址、文字、域名和类型会分别进入不同的列。文本 — 网址 每行复制一对“文字 — 地址”，网址 则只复制地址，每行一个。

能提取 mailto 和 tel 链接吗？

能。邮箱（mailto:）和电话（tel:、sms:）链接会连同文字一起出现在列表中，复制时与页面上完全一致。如果只想要这些链接，请在“过滤和设置”中选择类型 邮箱 或 电话。

在单页应用和动态网站上能用吗？

能。它读取的是标签页中脚本运行之后的页面，包括网页组件（shadow DOM）。如果滚动或点击“显示更多”后才加载更多链接，请滚动后在侧边栏中点击 刷新；当应用跳转到同一网站的另一个页面时，列表会自动更新。

给出的是完整的绝对网址，而不是相对路径吗？

是的。列表、复制内容和文件中的每个地址都是完整网址，解析方式与浏览器一致，包括带有 <base> 标签的页面。

如何从提取的网址中移除 UTM 和其他跟踪参数？

在“过滤和设置”中打开 移除 utm 等跟踪参数。它会从列表、复制内容和文件中移除 utm_source、fbclid、gclid 等跟踪标签，仅因这些标签而不同的链接会合并为一个。

会合并重复的链接吗？

会。相同的地址只出现一次，并显示它在页面上出现了多少次。在 重复项 下，你还可以选择把仅在 # 之后的部分或末尾斜杠不同的链接也合并。

如何只保留可见的链接？

这是默认行为：已收起菜单和隐藏区块中的链接不会出现在列表中。侧边栏会显示它们的数量，点击 +N 个已隐藏 就能把它们加回来。

能过滤站内和站外链接，或只看 PDF 和图片吗？

能。“过滤和设置”中有站内或站外链接、类型（网页、文件、邮箱、电话）、域名，以及 nofollow、sponsored、ugc。类型 文件 涵盖 PDF、ZIP、图片和其他文件；想只看某一种，请在搜索框中输入 .pdf。

如何得到一份干净的 Google 搜索结果地址列表？

在 Google 或 Bing 的结果页上，侧边栏提供 只看结果：只列出搜索结果，按顺序排列，不含广告，也不含搜索引擎自身的链接。

能只获取网页某一部分的链接吗？

能。选中那一部分，右键点击，选择 获取所选内容中的链接：只会列出所选内容里的链接。

需要注册吗？它会把我的链接发到别处吗？

无需账号，无需登录，完全免费，没有付费功能，也没有广告。列表在你的浏览器中生成，扩展不会发出任何网络请求：你的链接只会进入剪贴板或你下载的文件。我们的网站会统计扩展的安装、低分评价和卸载次数；具体内容见隐私政策。

它做不到什么？

它只处理你打开的这个标签页：不会抓取整个网站，不会顺着链接跳转，也不会检查链接是否可用（状态码）。Chrome 不允许扩展读取 Chrome 应用商店页面或 chrome:// 页面；来自其他网站的嵌入框架中的链接需要你的授权；侧边栏会告诉你页面的哪一部分没能读取。
