如何按页面顺序把链接文字和网址成对复制到 Excel

添加到 Chrome——免费

简短回答：打开网页，点击 Link Extractor 图标，打开 复制网址 旁边的菜单，选择 Excel 表格。粘贴到 Excel 或 Google 表格：网址和链接文字各占一列，每个链接一行，按页面顺序排列。

适合哪些人

检查锚文本的 SEO 人员，整理资料来源清单的编辑，以及所有不仅想知道网页链接到哪里、还想知道每个链接写了什么的人。

同时得到文字和网址的三种方式

  • Excel 表格（在 复制网址 旁边的菜单中）：带表头的表格——网址、文字、域名、类型等。粘贴到表格里，它会自动分成多列。
  • 文本 — 网址（同一个菜单）：每行一对“文字 — 地址”，适合放进文档、邮件或聊天。
  • CSV：列相同的文件，适合想保存下来或以后再打开的情况。参见如何把链接导出为能在 Excel 中打开的 CSV。

同一个菜单里的 网址 只复制地址，每行一个。

操作步骤

  1. 打开网页，点击 Link Extractor 图标（Alt+Shift+L，Mac 上是 Ctrl+Shift+L）。
  2. 可选：用搜索框或 过滤和设置 缩小列表。
  3. 打开 复制网址 旁边的菜单，选择 Excel 表格 或 文本 — 网址。
  4. 粘贴到你的表格或文档中。

文字和顺序是怎么确定的

  • 文字就是你在链接上看到的内容，多余的空格和换行会被合并。图片链接用的是图片的 alt 文字；如果没有，就用链接的标签或标题。完全没有文字的链接会被标为无文字。
  • 顺序就是页面的顺序，自上而下，包括网页组件内部的链接。
  • 重复项合并为一行，放在该链接第一次出现的位置，并带有它在页面上出现次数的计数。如果第一个副本是没有文字的图片（商品图、标志），这一行会采用后面有文字的副本的文字。
  • 完整地址：像 /about 这样的相对链接会变成完整网址，解析方式与浏览器一致。

什么时候换别的工具更合适

  • 其他网站指向你网站的链接的锚文本（反向链接）。这类数据来自 Ahrefs 或 Semrush 等反向链接工具；Link Extractor 读取的是你打开的那个页面。
  • 整个网站的锚文本。Link Extractor 不会抓取网站；这是网站审计工具的工作。

常见问题

能保留每一次出现，而不合并重复项吗？

相同的地址始终只占一行，并带有计数。在 重复项 下，你可以选择把仅在 # 之后的部分或末尾斜杠不同的链接也合并。

Excel 表格在 Google 表格中也能用吗？

能。粘贴到一个单元格里，它会以同样的方式填满各列。

能只获取网页某一部分的配对吗？

能。选中那一部分，右键点击，选择 获取所选内容中的链接，然后按上面的方法复制。
