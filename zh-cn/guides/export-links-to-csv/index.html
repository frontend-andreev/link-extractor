如何把网页上的所有链接导出为能在 Excel 中打开的 CSV

添加到 Chrome——免费

简短回答：安装 Link Extractor，打开网页，点击扩展图标，再点击 CSV。你会得到一个文件，每个链接一行，按页面顺序排列，包含完整网址和链接文字。文件采用带字节顺序标记（BOM）的 UTF-8 编码，所以 Excel 能正确显示中文、西里尔文、阿拉伯文和带重音符号的文字。

适合哪些人

检查网页链接的 SEO 人员，整理外联或竞品名单的营销人员，保存资料来源的研究者，以及所有想把某个网页的链接放进电子表格、而不想手动逐个复制的人。

好的导出应该是什么样

  • 完整地址。是 https://example.com/about，而不是 /about。
  • 链接文字单独一列，紧挨着网址。
  • 页面顺序，自上而下，表格和你看到的页面一致。
  • 无重复：同一个链接在菜单和页脚各出现一次，也只算一行。
  • 在 Excel 中文字可读。没有字节顺序标记时，Excel 常常把 UTF-8 文件打开成 Ð¿Ñ€Ð¸Ð²ÐµÑ‚ 这样的乱码，而不是真正的文字。
  • 正确的分隔符。有些国家的 Excel 期望逗号，有些期望分号；用错了，所有内容都会挤在 A 列。
  • 长页面不被截断。

操作步骤

  1. 在 Chrome 中打开网页。如果它需要滚动或点击“显示更多”才加载更多链接，请先滚动。
  2. 点击工具栏中的 Link Extractor 图标，或按 Alt+Shift+L（Mac 上是 Ctrl+Shift+L）。侧边栏会列出页面上的所有链接。
  3. 可选：缩小列表。在搜索框中输入，或打开 过滤和设置，按域名、类型、站内或站外链接，以及 nofollow、sponsored、ugc 筛选。文件中包含的就是此刻列表里的链接。
  4. 点击 CSV，文件会立即下载。
  5. 双击文件，用 Excel 打开。

如果 Excel 把所有内容放进了一列

这是分隔符与你的 Excel 不匹配。下载完成后，侧边栏会询问 Excel 中所有内容都在一列？，并提供用另一种分隔符重新下载文件的选项。想永久更改，请在“过滤和设置”的 CSV 分隔符 中选择 逗号 或 分号。默认情况下（自动）会跟随 Chrome 的语言。

文件里有什么

每个链接一行，另有一行表头：url、text、 domain、scope（站内或站外）、type（网页、 文件、邮箱、电话）、rel（nofollow、sponsored、ugc）、count（该链接在页面上出现的次数）以及其他几列。当链接经过 google.com/url?q=… 这样的重定向时，url 列是真实地址，original_url 保留页面上的原始地址。

以 =、+、- 或 @ 开头的值，前面会加一个撇号，这样 Excel 会把它当作文本，不会当作公式运行。Excel 可能会在单元格里显示这个撇号。

不用文件：直接粘贴到表格

打开 复制网址 旁边的菜单，选择 Excel 表格，然后粘贴到 Excel 或 Google 表格：网址、文字、域名和类型会进入不同的列。在 Google 表格中，也可以通过“文件 → 导入”导入 CSV。

什么时候换别的工具更合适

  • 整个网站所有页面的链接。Link Extractor 不会抓取网站：它只读取你打开的这一个标签页。要处理整个网站，请使用网站审计工具，例如 Screaming Frog SEO Spider。
  • 检查哪些链接已失效。它不检查状态码；这是链接检查工具的工作。
  • Chrome 应用商店和 chrome:// 页面。Chrome 不允许任何扩展读取它们。

常见问题

由 JavaScript 添加的链接会出现在文件里吗？

会。侧边栏读取的是标签页中脚本运行之后的页面，需要登录才能看到的页面也一样。而在自己的服务器上加载网页的在线提取工具，这两种都看不到。

有 10,000 个链接的页面能完整导出吗？

能。CSV 包含列表中的每一个链接，不会被截断。侧边栏最多从一个页面读取 200,000 个链接，超出时会提示你。

隐藏菜单里的链接会出现在文件里吗？

默认不会：列表只包含你能看到的链接，侧边栏会显示有多少被隐藏。点击 +N 个已隐藏 可把它们加入列表和文件。

需要账号吗？我的链接会去哪里？

无需账号，完全免费。列表在你的浏览器中生成；链接只会进入你下载的文件。详见隐私政策。
