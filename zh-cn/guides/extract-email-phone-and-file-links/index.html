Link Extractor · 使用指南

如何提取网页上的邮箱、电话和 PDF 链接

添加到 Chrome——免费

简短回答：打开网页，点击 Link Extractor 图标，打开 过滤和设置，在 类型 下选择 邮箱、电话 或 文件。列表只保留这些链接，复制网址 或 CSV 给你的也只有它们。

适合哪些人

从团队介绍页、名录或供应商清单中收集联系方式的人，以及需要网页上链接的每一个 PDF、文档或压缩包的人：报告、价目表、课程资料、下载文件。

哪些链接算作哪一类

  • 邮箱：mailto: 链接。
  • 电话：tel: 和 sms: 链接。
  • 文件：地址以文件扩展名结尾的链接——PDF；Word、Excel 和 PowerPoint 文档；OpenDocument、RTF、TXT、CSV 和 EPUB；ZIP、RAR、7z 等压缩包；图片；音频和视频；安装程序和磁盘映像——以及页面上标记为下载的任何链接。
  • 网页：所有其他网页链接。

在 类型 下什么都不选，就表示所有类型。

操作步骤

  1. 打开网页，点击 Link Extractor 图标（Alt+Shift+L，Mac 上是 Ctrl+Shift+L）。
  2. 打开 过滤和设置。
  3. 在 类型 下选择 邮箱、电话 或 文件；可以多选。
  4. 如果只要某一种文件，也在搜索框中输入它：.pdf 只保留 PDF， .docx 只保留 Word 文档。
  5. 点击 复制网址；或点击 CSV，得到包含每个链接的文字和类型的文件。

你会得到什么

邮箱和电话链接的复制结果与页面上完全一致，例如 mailto:sales@example.com 或 tel:+15551234567，在列表和文件中，链接文字就在它们旁边。重复项会合并，所以出现在页眉和页脚的同一个地址只算一行。文件链接是可以打开或下载的完整网址。

限制，直说

  • 只处理链接。以纯文本而不是链接形式写出的邮箱地址或电话号码，不会出现在列表中。Link Extractor 列出的是链接；它不会搜索页面文字。
  • 文件是按地址识别的。以 /download?id=42 这样的形式结尾的下载链接没有扩展名；除非页面把它标记为下载，否则会被算作网页。
  • 它不会下载这些文件。你得到的是它们的地址；它不发出任何网络请求。
  • 站内 和 站外 过滤器会隐藏邮箱和电话链接，因为它们不属于任何网站。

什么时候换别的工具更合适

  • 整个网站的联系方式。Link Extractor 不会抓取网站；它只读取你打开的这一个页面。
  • 一次下载所有文件。把复制的网址粘贴到下载管理器中。

常见问题

复制邮箱地址时会带上“mailto:”吗？

会，链接按页面上的样子复制，包括任何 ?subject= 部分。想要纯地址的话，请在电子表格中用查找和替换去掉 mailto:。

能获取框架里的页面所链接的 PDF 吗？

能，同一网站的框架会和页面一起读取。来自其他网站的框架需要你的授权，没能读取时侧边栏会告诉你。

免费吗？

免费。无需账号，没有付费功能，链接留在你的浏览器里。
