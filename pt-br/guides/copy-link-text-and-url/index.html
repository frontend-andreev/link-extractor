Como copiar pares de texto do link e URL para o Excel, na ordem da página

Adicionar ao Chrome — é grátis

Resposta curta: abra a página, clique no ícone do Link Extractor, abra o menu ao lado de Copiar URLs e escolha Tabela para Excel. Cole no Excel ou no Google Sheets: a URL e o texto do link vão para colunas próprias, uma linha por link, na ordem da página.

Para quem é

Profissionais de SEO que conferem textos âncora, editores que montam uma lista de fontes e qualquer pessoa que precise saber não só para onde uma página linka, mas o que cada link diz.

Três jeitos de pegar texto e URL juntos

  • Tabela para Excel (no menu ao lado de Copiar URLs): uma tabela com linha de cabeçalho — URL, texto, domínio, tipo e mais. Cole numa planilha e ela se divide em colunas.
  • Texto — URL (mesmo menu): um par “texto — endereço” por linha, para um documento, um e-mail ou um chat.
  • CSV: um arquivo com as mesmas colunas, para guardar ou abrir depois. Veja como exportar links para um CSV no Excel.

URLs, no mesmo menu, copia só os endereços, um por linha.

Passo a passo

  1. Abra a página e clique no ícone do Link Extractor (Alt+Shift+L, no Mac Ctrl+Shift+L).
  2. Opcional: reduza a lista com o campo de busca ou com Filtros e configurações.
  3. Abra o menu ao lado de Copiar URLs e escolha Tabela para Excel ou Texto — URL.
  4. Cole na sua planilha ou no seu documento.

Como o texto e a ordem são escolhidos

  • Texto é o que você vê no link, com espaços extras e quebras de linha reduzidos. Para um link de imagem, é o texto alternativo (alt) da imagem; se não houver, o rótulo ou o título do link. Um link sem texto nenhum é marcado como sem texto.
  • Ordem é a ordem da página, de cima para baixo, inclusive links dentro de web components.
  • Repetições são uma só linha, colocada onde o link aparece pela primeira vez, com um contador de quantas vezes ele está na página. Se a primeira cópia é uma imagem sem texto (uma foto de produto, um logotipo), a linha usa o texto de uma cópia posterior que tenha.
  • Endereços completos: links relativos como /about viram URLs completas, resolvidas do jeito que o navegador as resolve.

Quando outra ferramenta é a melhor escolha

  • Textos âncora de links de outros sites para o seu (backlinks). Esses dados vêm de ferramentas de backlinks, como Ahrefs ou Semrush; o Link Extractor lê a página que você abriu.
  • Textos âncora de um site inteiro. O Link Extractor não rastreia; uma ferramenta de auditoria de sites faz isso.

Perguntas

Posso manter cada ocorrência em vez de reunir as repetições?

O mesmo endereço é sempre uma só linha, com um contador. Em Duplicados você pode escolher reunir também links que diferem só pela parte depois do # ou por uma barra no final.

A Tabela para Excel funciona no Google Sheets?

Sim. Cole numa célula e ela preenche as colunas do mesmo jeito.

Posso pegar os pares de só uma parte da página?

Sim. Selecione essa parte, clique com o botão direito e escolha Coletar links da seleção; depois copie como descrito acima.
